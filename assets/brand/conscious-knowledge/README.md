# Conscious Knowledge — marca da empresa

Onde a marca da **empresa** aparece: rodapé, página "sobre" e assinatura institucional.
Ela nunca substitui a marca do produto no cabeçalho do app.

Coloque aqui, com estes nomes exatos:

```
logo-full.png
logo-compact.png
symbol.png
logo-mono.png
favicon.png
```

Depois, em `js/ui/brand.js`, troque `USE_OFFICIAL_ASSETS = false` para `true`.

As regras de uso estão em `../README.md`.
